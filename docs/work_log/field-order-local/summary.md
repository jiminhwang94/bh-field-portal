# 항목 순서는 기기에만 · 올리기 버튼 두 곳 동시 잠금 (v3.26.3)

## 날짜
2026-09-16

## 요약
두 가지를 고쳤다.
1. **리포트 항목 순서를 기기에만 저장한다.** 남이 자기 태블릿에서 항목을
   옮기면 내가 맞춰 둔 양식이 다음 동기화에 날아가던 문제.
   항목을 **더하고 지우는 것은 지금처럼 팀 공통**이다.
2. **[구글 시트로 업로드] 버튼이 위·아래 두 곳에 있는데**, 하나를 눌러도
   둘 다 '올리는 중' 으로 바뀌게 했다.

## 1. 항목 순서 — 기기 전용

### 왜
순서는 사람마다 손에 익은 것이 달라 팀이 같아야 할 이유가 없다. 그런데
`reorderFields()` 가 순서를 바꿀 때마다 시트 푸시를 대기열에 넣었고,
`pullFields()` 는 시트의 `displayOrder` 로 기기 순서를 덮어썼다.
→ 두 사람이 서로 다른 순서를 좋아하면 **동기화할 때마다 서로의 양식을
지우는 싸움**이 된다.

### 어떻게
- `store.reorderFields()` — `queueFieldSheetPushIfOn` 호출을 **뺐다.**
  순서는 IndexedDB 에만 남는다.
- `fieldsheet.pullFields()` — `displayOrder: found ? found.displayOrder : (lastOrder += 1)`.
  이미 있는 항목은 **내 순서를 지키고**, 남이 새로 만든 항목만 내 목록
  맨 뒤에 붙인다.
- `fieldsheet.mergeWithSheet()` — 시트 줄 차례대로 담으므로 올릴 때
  **시트 순서를 건드리지 않는다.** `changes` 가 없을 때 그냥 `local` 을
  돌려주던 지름길을 없앴다 (그 길로 가면 내 순서가 시트를 덮었다).
- 지우기는 계속 전달되어야 하므로, 내가 지운 항목을 `changes` 의
  `before` 에서 **이름으로** 모아(`removed`) 시트 줄에서 걸러낸다.
  ID 는 기기마다 다를 수 있어 ID 로만 보면 삭제가 안 먹었다.
- 화면: 순서 바꾼 뒤 안내를 "이 기기에만 적용됩니다" 로.

### 시트 열 순서는?
월별 리포트 탭의 열 순서는 v3.26 단일 표 설계에서 **이름으로** 맞추고
새 항목만 제자리에 끼워 넣는다. 기기마다 항목 순서가 달라도 시트 열은
흔들리지 않는다 (`test_apps_script.mjs` 의 "순서 이동은 시트를 건드리지
않는다" 검사).

## 2. 올리기 버튼 — 위아래가 한 몸

`#btn-topaction`(상단바)은 폼 아래 제출 버튼을 대신 눌러 주는 버튼인데,
누르면 **폼 버튼만** '올리는 중' 으로 바뀌고 상단 버튼은 멀쩡해 보였다.
→ 한 번 더 누르게 된다.

- `report.js` 에 `setSubmitState(text, busy)` 를 두고 두 버튼의 글자·잠금을
  한 번에 바꾼다. 저장 중 · 올리는 중 · 원래대로 세 자리 모두 이걸 쓴다.
- `app.js` `syncTopActionLabel()` 이 글자뿐 아니라 **`disabled` 까지** 폼
  버튼을 따라가게 했다. 안 그러면 올리는 도중 화면을 떠났다 돌아왔을 때
  상단 버튼만 잠긴 채 남아 다시는 못 누른다.
