# 화면 다듬기 — 상태 칸 선 두께 · 군더더기 걷어내기 (v3.26.4)

## 날짜
2026-09-16

## 요약
눈에 걸리던 세 가지를 걷어냈다.
1. 리포트 이력의 **조치 상태 칸만 선이 굵던 것**(2px)을 다른 버튼·입력칸과
   같은 1px 로 맞췄다.
2. 홈 화면의 **"무엇을 찾고 있습니까"** 문구를 없앴다.
3. 좌측 레일 맨 위의 **파란 네모(브랜드 마크)** 를 없앴다.

## 변경

### 1. 조치 상태 칸 (web/css/app.css)
`.status-select` 이 `border: 2px` 를 따로 선언해, 같은 화면의 월 선택칸 ·
[시트에서 받기] 버튼 · 검색 입력칸(모두 1px) 사이에서 이 칸만 겉돌았다.
→ **선언을 지웠다.** `.status-select` 은 `.select` 도 함께 쓰므로 기본 1px 을
그대로 따른다. 색 모디파이어(`--done`/`--watch`/`--doing`/`--swap`)는
`border-color` 만 바꾸므로 색 구분은 그대로다.
두께를 다시 올리지 않도록 주석에 이유를 남겼다 — 구분은 **색**이 하는 일이다.

실측(브라우저): 조치 상태 칸 1px · 월 선택칸 1px · 보조 버튼 1px ·
검색 입력칸 1px. 상태 칸의 선 **색**은 상태 색(초록 등)을 유지.

### 2. "무엇을 찾고 있습니까" (web/js/app.js · app.css)
검색칸 위 `.kicker` 한 줄을 지웠다. 입력칸에 이미
`placeholder="오류 코드 · 부품명 · 증상 · 명령어"` 와
`aria-label="통합 검색"` 이 있어 읽는 이도 · 스크린 리더도 잃는 것이 없다.
`.kicker` 는 이 한 곳에서만 쓰였으므로 CSS 규칙도 함께 지웠다(죽은 코드).

### 3. 좌측 레일의 파란 네모 (web/index.html · app.css)
`.tabbar__mark` (11×11 파란 사각형)는 장식이라 지웠다. 이미 좁은 화면에서는
`display: none` 으로 숨기고 있었으니 없어도 되는 것이었다.
HTML 의 `<span>`, `.tabbar__mark` 규칙, 좁은 화면 override 세 곳 모두 정리.
상단바에 `비욘드허니컴 현장 포털` 글자가 있어 브랜드는 그대로 보인다.
