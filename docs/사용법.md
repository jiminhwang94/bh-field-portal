# 현장 포털 사용법

필드 엔지니어용 안내입니다. 어려운 말 없이, 어디서 무엇을 누르면 되는지만 적었습니다.

---

## 1. 앱 설치하기 (안드로이드 태블릿 · 폰)

**Play 스토어에서 찾는 앱이 아닙니다.** APK 파일을 받아 직접 설치합니다.
"Google Play AR 서비스 필요" 같은 메시지는 다른 앱의 것이니 신경 쓰지 않아도 됩니다.

### APK 받는 곳 — 편한 쪽으로

1. **팀에서 받은 설치 링크** (구글 드라이브) — 가장 쉽습니다.
   이 주소는 바뀌지 않고, 누를 때마다 그때의 최신 버전을 줍니다.
   이미 앱이 있는 사람은 **설정 → 앱 설치 · 접속 주소** 에서도 이 링크를 볼 수 있습니다.
2. **GitHub Releases** — 저장소 Releases 페이지 맨 위 항목의 `.apk` 를 누릅니다.
   GitHub 에 로그인된 브라우저에서만 받아집니다. 로그인 없이 누르면 **아무것도 없는 흰 페이지**가 뜹니다.
3. **USB 로** — 로그인된 PC 에서 `.apk` 를 받아 USB 에 복사 → 태블릿 파일 앱에서 누릅니다.
   태블릿이 여러 대면 같은 USB 로 전부 설치하면 됩니다.

### 설치

1. `.apk` 를 누릅니다.
2. "출처를 알 수 없는 앱" 경고가 나오면 **[설정] → 이 출처 허용** (기기마다 처음 한 번만).
3. 홈 화면의 **현장 포털** 아이콘으로 엽니다.

### 처음 켰을 때

- 팀 시트에 **저절로 연결**되고 가이드 · 재고 · 이력을 받아 옵니다. 주소를 넣을 필요가 없습니다.
- **설정 → 내 이름 / 기기 이름** 에 이름을 등록해 두세요. 시트에 누가 올렸는지 이 이름으로 남습니다.
- 인터넷이 되는 곳에서 한 번 받아 두면, 그 뒤로는 인터넷 없이도 씁니다.

---

## 2. 업데이트하기

- 새 버전이 나오면 화면 위에 **[업데이트] 띠**가 뜹니다. 누르면 받아서 설치 화면이 열립니다.
  기존 앱 위에 덮어 설치되므로 **자료는 그대로** 남습니다.
- **"앱 업데이트가 필요합니다"** 화면이 덮으면 팀에서 옛 버전을 막은 것입니다. [받기] 를 누르세요.
  아직 올리지 못한 리포트 · 재고 변경은 기기에 그대로 있고, 업데이트 뒤 저절로 올라갑니다.
- 띠가 안 보이면 1장의 설치 링크로 받아 덮어 설치해도 됩니다.

> ⚠️ **앱을 지우고 다시 깔지 마세요.** 지우면 기기에만 있던 것(아직 올리지 못한 리포트 · 사진)이 함께 사라집니다.
> 설치가 "앱이 설치되지 않았습니다" 로 막히면 지우지 말고 관리자에게 먼저 알려 주세요.

### [패치 내용]

상단 **[새로고침]** 옆 **[패치 내용]** 을 누르면 버전마다 무엇이 바뀌었는지 짧게 볼 수 있습니다.
아직 안 본 새 버전이 있으면 버튼에 점이 찍힙니다.

## 3. 화면 구성

왼쪽 메뉴(폰에서는 아래쪽)에 **홈 · 새 리포트 · 리포트 이력 · 가이드 · 운행일지 · 차량 재고**, 맨 아래 **설정**이 있습니다.
위쪽에는 올리기 상태 칩과 **[패치 내용] · [새로고침]** 이 있습니다.

| 화면 | 하는 일 |
|---|---|
| **홈** | 큰 문 세 개 — **새 리포트**(이어 쓰기 · 접수 대기) · **리포트 이력**(진행 중 · 교체 예정 · 7일 넘음) · **가이드**. 그 아래 운행일지 · 차량 재고. 맨 위 **확인할 것** 띠에는 올리지 못한 것 · 남이 먼저 고친 가이드 · 7일 넘게 끝나지 않은 리포트가 뜹니다 |
| **새 리포트** | 한 화면에 질문 하나씩 묻습니다 (아래 4장) |
| **리포트 이력** | 팀이 올린 리포트 전부. 상태별 숫자 · 검색 · 상세. 상태를 여기서 바꿉니다 |
| **매장별 이력 · 통계** | 이력에서 매장 이름을 누르면 그 매장의 방문 기록 · 자주 난 오류. 통계는 달마다 건수 · 자주 쓴 부품 등 |
| **가이드** | 로봇(Gen.1 · Gen.2 · Zephyr …)을 고르고 오류 코드 · 하드웨어 교체 · SW·명령어 중에서 찾습니다. 단계 체크 · 명령어 복사 · '이 로봇 지난번' 메모 |
| **운행일지** | 차량별 운행 기록 (국세청 서식). 주행 전 거리는 지난번 주행 후 거리가 미리 들어갑니다 |
| **차량 재고** | 칩(전체 · 부족만 · 분류)으로 거르고, 고른 품목을 큰 [−] [＋] 로 바꿉니다 |
| **설정** | 구글 시트 연결 상태 · 확인할 것 · 리포트 항목 · 내 이름 · 앱 설치 링크 · 보기(고대비) · **휴지통** · 테스트 모드 |

햇빛 아래에서 글자가 안 보이면 **설정 → 보기 → 고대비** 를 켜세요.

## 4. 리포트 쓰기

**홈 → 새 리포트** (또는 왼쪽 메뉴). 한 화면에 질문 하나씩, 아래 차례로 묻습니다.

1. **접수 건** — 매장이 접수한 건이 목록에 있으면 누르세요. 매장명이 채워집니다.
2. **로봇** — 이 매장에서 본 로봇은 위에서 바로 고릅니다.
3. **증상** — 이슈 유형을 고르고 오류 코드 · 덧붙일 말을 적습니다.
   정확한 오류 코드를 적으면 그 **가이드**가 뜨고, 같은 로봇에서 같은 코드가 또 나왔으면 맨 위에 알려 줍니다.
4. **사진** — 카메라가 바로 열립니다. 사진 · 영상 여러 장을 붙일 수 있습니다.
5. **원인** — 증상마다 원인을 고릅니다. 못 찾았으면 [원인 모름].
6. **조치 · 결과** — 무엇을 했는지, 처리 결과를 고릅니다. 쓴 부품은 **[부품 추가]** 로 고르면 올릴 때 내 차량 재고에서 빠집니다.
7. **확인** — 빈 필수 칸이 있으면 [고치기] 로 그 단계에 데려가 줍니다. 확인하고 올립니다.

- **[한 번에 보기]** 를 누르면 예전처럼 한 화면에 전부 나옵니다.
- 쓰는 중인 내용은 **바로 기기에 임시보관**됩니다. 앱이 꺼져도 홈의 **이어 쓰기**로 돌아옵니다.
- 사진은 올리기 전에 가로 · 세로 최대 1600px 로 줄여 보냅니다. 원본은 기기에 남습니다.
- 첨부 한도: **파일 하나 25MB, 리포트 하나 60MB.** 넘는 파일은 빠지고 이유가 표시됩니다.
  APK 로 찍은 영상은 저절로 줄여서 1분이 약 17MB 입니다.
- 큰 첨부는 조각으로 나눠 올립니다. 중간에 끊겨도 받은 조각 다음부터 이어 올립니다.

### 상태와 처리 결과

| | 뜻 | 바뀌나 |
|---|---|---|
| **처리 결과** (리포트에 적는 것) | 그날 현장에서 정해진 사실 | 안 바뀜 — 기록으로 남음 |
| **상태** (이력 화면) | 지금 이 건이 어디까지 왔나 — 조치 완료 · 모니터링 · 조치 진행 중 · 교체 예정 | 이력에서 계속 바꿈 |

처음 상태는 처리 결과에서 가져옵니다 (완료 → 조치 완료, 재방문 필요 → 조치 진행 중, 부품 대기 → 교체 예정, 모니터링 → 모니터링).
이력에서 상태를 바꾸면 시트의 `상태` 칸에 기록됩니다.

## 5. 인터넷이 없을 때 (오프라인)

자료가 기기 안에 있어서 **인터넷이 없어도 거의 다 됩니다.**

| 하는 일 | 오프라인 | 온라인 |
|---|---|---|
| 가이드 보기 · 찾기 · 고치기 | ✅ | ✅ |
| 리포트 쓰기 (사진 포함) | ✅ 기기에 저장 | ✅ |
| 재고 [−] [＋] · 운행일지 | ✅ 기기에 저장 | ✅ |
| 시트에 올리기 | ⏳ 쌓였다가 **연결되면 저절로** | ✅ 바로 |
| 다른 사람이 바꾼 것 받기 | ❌ | ✅ [새로고침] |

- 오프라인이면 화면 위에 **"오프라인 — 기기에 저장하며 계속 사용할 수 있습니다"** 띠가 뜹니다.
- **올리기는 자동입니다.** 누를 버튼이 없습니다. 인터넷이 돌아오면 쌓인 것부터 올라갑니다.
- **[새로고침] 은 받기 버튼입니다.** 다른 사람이 바꾼 내용을 지금 받아 옵니다 (밀린 것이 있으면 먼저 보냅니다).
  앱이 5분마다 시트에 새 내용이 있는지만 물어보고, 있으면 [새로고침] 에 점을 켭니다.
- LTE 든 어느 와이파이든 인터넷만 되면 됩니다.

### 상단 칩 — 밀린 것이 있을 때만 보입니다

| 칩 | 뜻 |
|---|---|
| (안 보임) | 정상. 다 올라갔습니다 |
| `오프라인 · 올릴 것 3건` | 인터넷이 없습니다. 연결되면 올라갑니다 |
| `올리는 중 3건` | 지금 보내는 중 |
| `대기 3건` | 곧 다시 보냅니다 |
| `못 보냄 3건` | 올리기가 실패했습니다. 칩을 눌러 이유를 보세요 |

칩을 누르면 **[올릴 내용]** 목록이 열립니다. 항목을 누르면 고칠 화면으로 가고,
**[되돌리기]** 를 누르면 그 변경을 바꾸기 전으로 돌립니다.

### 둘이 같은 것을 고쳤을 때

- **가이드**: 내가 고치는 사이 다른 사람이 먼저 올렸으면 덮어쓰지 않고 **충돌**로 보관합니다.
  홈 알림이나 **설정 → 확인할 것** 에서 [내 것으로 덮기] / [남의 것 그대로] 를 고르세요.
- **재고 수량**: 바뀐 만큼만 올라갑니다. 둘이 같은 칸에 +1, +2 를 해도 시트는 +3 이 됩니다.

---

## 6. 실수로 지웠을 때

지운 가이드 · 리포트는 바로 사라지지 않습니다.
**설정 → 휴지통** 을 열면 (인터넷 필요) 지운 목록이 나오고, **[되살리기]** 를 누르면 원래 자리로 돌아갑니다.
리포트에 붙어 있던 사진 · 영상도 함께 돌아옵니다.

---

## 7. 문제가 생기면

- **"못 보냄"** 이 계속 뜨면 → 칩을 눌러 이유를 보고, 인터넷이 되는 곳에서 [새로고침] 을 한 번 눌러 보세요.
  그래도 안 되면 이유 화면을 찍어 관리자에게 보내 주세요. 기기에서 난 오류는 시트에도 저절로 모입니다.
- **앱이 이상하게 보이면** → 앱을 완전히 닫았다가 다시 여세요. 그래도 같으면 관리자에게.
- **절대 하지 말 것** → 앱 지우기 (올리지 못한 것이 사라집니다).
