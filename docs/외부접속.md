# 사무실 밖에서도 가이드 주고받기

## 먼저 — 이게 정말 필요한가

대부분은 **필요 없습니다.** 지금 구조에서 사무실 서버가 필요한 것은 하나뿐입니다.

| 하는 일 | 어디를 거치나 | 사무실 밖에서 |
|---|---|---|
| 리포트 → 구글 시트 업로드 | 기기 → 구글 | ✅ 됨 |
| 차량 재고 (수량·품목) | 기기 ↔ 구글 시트 | ✅ 됨 |
| 리포트 이력 열람·상태 변경 | 기기 ↔ 구글 시트 | ✅ 됨 |
| 가이드 열람·검색 | 기기 안 | ✅ 됨 (오프라인도) |
| **가이드·항목 설정 주고받기** | 기기 ↔ **사무실 서버** | ❌ 사무실 Wi-Fi 필요 |

즉 **가이드를 현장에서 고쳐 바로 팀에 넘겨야 할 때**만 이 문서가 필요합니다.
가이드는 자주 바뀌지 않으므로, 사무실에 들어와서 [⬆ 업데이트] 를 누르는 것으로
충분한 경우가 많습니다.

> 참고: v3.3 부터 가이드도 **구글 시트의 탭**과 양방향으로 오갑니다.
> 시트에서 고치는 방식으로 쓴다면 사무실 서버 없이도 팀 공유가 됩니다.
> 이 문서의 방법은 "앱에서 고쳐서 바로 넘기고 싶을 때" 를 위한 것입니다.

---

## 방법 1. 임시 주소 (가장 간단 · 계정 불필요)

필요할 때만 잠깐 여는 방식입니다.

1. 사무실 PC 에서 `tools\외부접속 열기.bat` 더블클릭
2. 처음이면 `cloudflared` 설치를 물어봅니다 → **Y**
3. 창에 `https://무작위이름.trycloudflare.com` 주소가 뜹니다
4. 그 주소를 태블릿 **[⚙️ 설정 → 사무실 서버 주소]** 에 넣습니다

**제약**
- 창을 닫으면 끊깁니다 (PC 는 켜져 있어야 합니다)
- **켤 때마다 주소가 바뀝니다** — 태블릿 설정을 매번 고쳐야 합니다
- 그래서 상시 운영에는 맞지 않습니다

## 방법 2. 고정 주소 (상시 운영 · Cloudflare 계정 필요)

주소가 바뀌지 않아 태블릿 설정을 한 번만 하면 됩니다.
**무료 요금제로 충분합니다.** 다만 도메인이 하나 있어야 합니다.

### 사장님이 직접 하셔야 하는 부분

제가 대신 할 수 없습니다 — 구글 계정 승인과 마찬가지로 Cloudflare 계정 로그인이
필요하기 때문입니다. 순서만 적어 둡니다.

**① 계정과 도메인 준비**
1. [dash.cloudflare.com](https://dash.cloudflare.com) 가입 (무료)
2. 보유 도메인을 등록 → 안내대로 네임서버를 Cloudflare 것으로 변경
   (도메인이 없으면 `beyondhoneycomb.com` 의 하위 이름을 쓰면 됩니다)

**② 이 PC 를 Cloudflare 에 연결** — 브라우저 승인 창이 뜹니다
```bash
cloudflared tunnel login
```

**③ 터널 만들기** (이름은 아무거나)
```bash
cloudflared tunnel create bh-portal
```

**④ 주소 연결** — `portal` 부분은 원하는 이름으로
```bash
cloudflared tunnel route dns bh-portal portal.beyondhoneycomb.com
```

**⑤ 설정 파일 만들기** — `%USERPROFILE%\.cloudflared\config.yml`
```yaml
tunnel: bh-portal
credentials-file: C:\Users\User\.cloudflared\<터널ID>.json

ingress:
  - hostname: portal.beyondhoneycomb.com
    service: http://localhost:8787
  - service: http_status:404
```

**⑥ 윈도우 서비스로 등록** — PC 를 켜면 자동으로 붙습니다
```bash
cloudflared service install
```

**⑦ 태블릿 설정**
[⚙️ 설정 → 사무실 서버 주소] 에 `https://portal.beyondhoneycomb.com` 입력.
이후 주소가 바뀌지 않습니다.

## ⚠️ 외부에 열기 전에 반드시 읽어 주세요

지금 앱에는 **접근 제한이 없습니다.** v3.2 에서 PIN 기능을 없앴기 때문입니다.
사내망에서만 쓸 때는 문제가 없었지만, 위 방법으로 주소를 공개하면
**그 주소를 아는 사람은 누구나 가이드와 재고를 볼 수 있습니다.**

외부에 열 계획이라면 아래 중 하나를 먼저 붙이는 것을 권합니다.

| 방법 | 특징 |
|---|---|
| **Cloudflare Access** (권장) | Cloudflare 쪽에서 막습니다. 앱을 고칠 필요가 없고, 구글 계정으로 로그인시킬 수 있습니다. 무료 요금제에서 50명까지 |
| 접근 PIN 되살리기 | v3.2 에서 지운 기능입니다. git 이력에 남아 있어 되살릴 수 있습니다 |
| 방법 1(임시 주소)만 쓰기 | 필요할 때만 잠깐 열고 닫습니다. 노출 시간이 짧습니다 |

**Cloudflare Access** 는 대시보드에서 Zero Trust → Access → Applications 로
몇 번 눌러 설정합니다. 앱 코드는 그대로 두면 됩니다.

## 방법 3. 클라우드로 서버 옮기기

사무실 PC 가 꺼져 있어도 되게 하려면 서버 자체를 옮기면 됩니다.
`server.py` 는 파이썬 표준 라이브러리만 쓰므로 아무 리눅스 서버에서나 그대로 돕니다.

- 월 5천~1만원 수준 (Lightsail·Oracle Free Tier 등)
- 단일 장애점(사무실 PC)이 사라집니다
- 대신 서버 관리가 생깁니다

필요해지면 그때 상의해 주세요.
